### Exclusions and limitations

**When not to use:** The delta ratio is only meaningful in metabolic acidosis with an elevated anion gap; it is omitted when those conditions are not met. Do not interpret it in isolation from the clinical picture.

- Laboratory-specific reference intervals and the patient's baseline matter. Albumin correction and delta ratios have important validation limitations and must not diagnose a mixed disorder in isolation.

## Outputs

| Field | Type | Availability | Primary | Description |
| --- | --- | --- | --- | --- |
| `anion_gap` | number · mEq/L | Always | Yes | Na − (Cl + HCO3), rounded to 1 decimal place. |
| `albumin_corrected_anion_gap` | number · mEq/L | When any of: albumin | No | Anion gap + 2.5 × (4 − albumin), rounded to 1 decimal place. |
| `delta_anion_gap` | number · mEq/L | Always | No | ΔAG = anion gap − 12, rounded to 1 decimal place. |
| `albumin_corrected_delta_anion_gap` | number · mEq/L | When any of: albumin | No | Albumin-corrected ΔAG = corrected anion gap − 12, rounded to 1 decimal place. |
| `delta_ratio` | number | Compute condition: uncorrected_delta_ratio_applicable | No | Delta gap / (24 − HCO3), rounded to 2 decimals. Returned only when bicarbonate is below 24 mEq/L and the uncorrected anion gap exceeds 12 mEq/L. |
| `albumin_corrected_delta_ratio` | number | Compute condition: corrected_delta_ratio_applicable | No | Albumin-corrected delta gap / (24 − HCO3), rounded to 2 decimals. Returned only when albumin is supplied, bicarbonate is below 24 mEq/L, and the corrected anion gap exceeds 12 mEq/L. |
