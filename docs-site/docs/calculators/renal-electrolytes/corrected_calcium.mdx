### Exclusions and limitations

**When not to use:** Do not use the adjusted value to diagnose, classify, or manage calcium status. Prefer measured ionized calcium when accuracy matters.

- Do not use albumin-adjusted calcium to classify or manage calcium status. Current laboratory-medicine guidance recommends measured ionized calcium when accurate calcium assessment is required.
