---
title: Deployment
description: The operational boundary around a hosted OathMCP service.
---

An operator is responsible for authentication, authorization, transport
security, origin policy, monitoring, abuse prevention, availability, data
minimization, consent, retention, deletion, audit logging, incident response,
and every jurisdiction-specific privacy, cybersecurity, professional-practice,
and medical-device obligation.

Before release, verify health, MCP initialization, tool listing, discovery,
description, deterministic calculation, typed failure behavior, evidence
resources, and the canonical Responsible Use resource through the real deployed
transport.

Record the package version, source commit, deployment identifier, UTC time,
verification result, and previous deployable version. Do not silently serve a
clinically changed contract under an unchanged release record.
