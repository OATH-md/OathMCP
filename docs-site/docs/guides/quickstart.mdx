## Hosted Streamable HTTP

Use the official stateless endpoint:

```text
https://mcp.oath.md/mcp
```

The public endpoint is unauthenticated and must not receive names, record
numbers, free-text notes, or other protected or personal health information.

## Local stdio

Run the exact reviewed npm release:

```json title="MCP client configuration"
{
  "mcpServers": {
    "oathmcp": {
      "command": "npx",
      "args": ["-y", "@oath-md/oath-mcp@0.2.1"]
    }
  }
}
```

## First calculation

Ask the server to describe BMI, then calculate only after confirming the adult
population and measured inputs:

```json title="describe_calculator"
{
  "id": "bmi"
}
```

```json title="calculate"
{
  "id": "bmi",
  "inputs": {
    "weight_kg": 70,
    "height_cm": 170
  }
}
```

The expected calculated BMI is `24.22 kg/m²`, with the declared adult screening
band “Normal weight.” The result is decision support, not a diagnosis or direct
measurement of adiposity.

:::tip
If you do not know the canonical calculator ID, start with `find_calculator`.
Do not guess a similarly named score or silently choose among variants.
:::
