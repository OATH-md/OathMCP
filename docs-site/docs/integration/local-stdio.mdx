---
title: Local stdio
description: Run an exact OathMCP release as a local MCP subprocess.
---

Configure the exact reviewed npm release:

```json
{
  "mcpServers": {
    "oathmcp": {
      "command": "npx",
      "args": ["-y", "@oath-md/oath-mcp@0.2.1"]
    }
  }
}
```

The npm package is scoped, while its installed executable and MCP server
identity remain `oath-mcp`. Pin an exact reviewed version instead of accepting
a moving latest tag.

The server communicates over stdout. Route application logs elsewhere so they
cannot corrupt the MCP transport. OathMCP requires Node.js 22 or newer.
