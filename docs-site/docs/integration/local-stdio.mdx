---
title: Local stdio
description: Run OathMCP from source as a local MCP subprocess.
---

Until the first verified npm publication, clone and build the reviewed source:

```bash
git clone https://github.com/OATH-md/OathMCP.git
cd OathMCP
npm ci
npm run check
```

Then configure the built stdio entrypoint:

```json
{
  "mcpServers": {
    "oathmcp": {
      "command": "node",
      "args": ["/absolute/path/to/OathMCP/dist/server/stdio.js"]
    }
  }
}
```

Registry publication is currently disabled, including for the hosted `0.2.0`
release. When a package release is explicitly announced, pin its exact reviewed
version instead of accepting a moving latest tag.

The server communicates over stdout. Route application logs elsewhere so they
cannot corrupt the MCP transport. OathMCP requires Node.js 22 or newer.
