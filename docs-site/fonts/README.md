# Geist font assets

The documentation site self-hosts Geist and Geist Mono so production builds do
not depend on a mutable third-party font URL.

- Upstream: [vercel/geist-font](https://github.com/vercel/geist-font)
- Release: [`v1.7.2`](https://github.com/vercel/geist-font/releases/tag/v1.7.2)
- Release archive SHA-256: `7fc800d2ac6b92844895196e5041aca55d814c15db70c44f79b3b83ab82b04e2`
- License: SIL Open Font License 1.1; see [`OFL.txt`](OFL.txt)

The four WOFF2 files are the upstream variable Roman and italic webfonts for
Geist and Geist Mono. They are redistributed unchanged.
